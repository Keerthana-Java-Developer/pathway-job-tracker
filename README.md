## Overview

Pathway is a job application tracking platform designed to help users keep their job search organized. It combines a React frontend with a Java Spring Boot backend and MySQL persistence.

## Technology Stack

| Layer | Technologies |
|---|---|
| Frontend | React, JavaScript, Vite |
| Backend | Java, Spring Boot, REST APIs |
| Database | MySQL |
| Authentication | JWT |
| Development | Git, GitHub |

## Core Areas

- User registration and login
- Job application management
- Application status tracking
- Dashboard-oriented application overview
- Frontend and backend integration through REST APIs

*Feature availability may vary by deployed version.*

## Project Structure

The repository contains the frontend and backend application code. Open the respective project folders to review the implementation and configuration.

## Running Locally

1. Clone this repository.
2. Configure the MySQL database and backend environment.
3. Start the Spring Boot backend from its project directory.
4. Install frontend dependencies with `npm install`.
5. Start the frontend development server with `npm run dev`.

Refer to the configuration files in the repository and update local database credentials before running. Never commit production credentials or secret keys.
